# crypto-feed

Public market snapshots from Gli_Izmir.

- Data: `crypto-data/chatgpt_snapshot.json`
- Schema: version 1; `generated_at` is the snapshot time.
- Public fields contain market prices, ratios, rank and historical market statistics. Portfolio balances, positions, cost basis and private research must never be published here.
- Gli_Izmir publishes directly every five minutes. The manual GitHub workflow is a fallback from the existing public Gist.

The website lives in `anahtarr/burakakgul.com`; private snapshots and work remain in `anahtarr/crypto-private`.
